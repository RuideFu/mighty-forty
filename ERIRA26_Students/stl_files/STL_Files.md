# STL Files and G-Code Instructions

Please add any STL and G-Code files you make to this folder. You are allowed to make a subfolder for further organization as you see fit. If you need to remake or 
update any designs you made, please do not delete the original file from the repo, instead, please add "archive_" to the beginning of the file name and move them to
'/ERIRA26_Students/stl_files/archive'. Please format the files in the following way:

**lastname_whattheobjectis_erira26.stl**

**lastname_whatistheobject_printtime_erira26.gcode**
