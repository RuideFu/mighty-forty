# **Example of Documentation Expected**

This is not meant to take up a ton of your time, it is meant as a way for us to finalize all the documentation post ERIRA and create a thorough guide of the backup 
system. Generally, whenever you work on this project throughout the week you should write a short summary of your activities, individually or as a group, and any key
pieces of information in the file under your name. An example log is provided below. Formatting for GitGub markdown files is explained in /Resources/GitHub_md_files.md.
