## Pin Definition

from the front:
|  | v |  |
| --- | --- | --- |
| 1 |  | 2 |
| 4 |  | 3 |

(the v is the keying notch)

1. Red. Power +
2. Blue. DB9 pin 5 & Power -
3. Green. DB9 pin 3 (TX)
4. Yellow. DB9 pin2 (RX)

## Connector

- Factory default is 4 Pin M12 connector. e.g. [amazon](https://www.amazon.com/dp/B09YLP4JFY)

- Our custom cable is 4 Pin M12 (female) to a _different type of_ 4 Pin M12. ([example](https://adamconn.com/product/standard-industrial-cable-m12-connector-4-pin-aviation-plug))
