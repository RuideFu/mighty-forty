
Multimeters are measuring instruments that measure multiple electrical properties, such as Voltage, Resistance, Continuity, and Current. We have three different multimeter models with us, but they are share the same basic functions and can be used interchangeably. For the most part during this project you will only need to use the continuity mode, but it is useful to fully understand the functions of a multimeter and what it is doing. The <ins>most important thing</ins> while using a multimeter is to make sure whatever you are checking is <ins>**DISCONNECTED FROM ANY POWER SUPPLIES**</ins>. 

This is a very useful video for learning the basics on using a multimeter: [How to Use a Multimeter for Beginners - How to Measure Voltage, Resistance, Continuity and Amps](https://www.youtube.com/watch?v=TdUK6RPdIrA)
