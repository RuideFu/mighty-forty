# **Introduction to Operating Systems**

Here are a few operating system options for the Rpi 4b that I considered when designing the current system. There are of course other

| Name | Pros | Cons | Download |
| --- | --- | --- | --- |
| Raspberry Pi OS | Built specifically for the Pi, with strong hardware support out of the box. | Can slow down under heavy workloads. | [raspberrypi.com/software/operating-systems](https://www.raspberrypi.com/software/operating-systems/) |
| Ubuntu | Huge software repository and long-term support (LTS), making it easy to find packages and keep the system stable. | More resource-demanding than lighter alternatives. | [ubuntu.com/download/raspberry-pi](https://ubuntu.com/download/raspberry-pi) |
| Manjaro | Very speedy OS. | Comes with a lot of unnecessary desktop-oriented software and is slightly harder to modify. | [manjaro.org/products/download/arm](https://manjaro.org/products/download/arm/) |
| DietPi | Extremely lightweight OS. | Its lightweight nature may cause it to struggle to run threepio, but that's not a certainty — if you go with this one, start testing usability right away. | [dietpi.com/#download](https://dietpi.com/#download) |
| Fedora | Highly modifiable OS designed to resemble Windows 10/11, without the bloat. | More resource-intensive on the Pi in its default configuration. | [arm.fedoraproject.org](https://arm.fedoraproject.org/) |
